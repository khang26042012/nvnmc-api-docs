## Chi tiết một máy chủ

```http
GET https://panel.nvnmc.cloud/api/client/servers/{server_id}
```

### Tham số đường dẫn (Path Parameters)
| Tham số | Kiểu dữ liệu | Bắt buộc | Mô tả |
| :--- | :--- | :---: | :--- |
| **server_id** | string | Có | Mã định danh 8 ký tự của máy chủ (ví dụ: `abd90cdd`). |
